# 5　授業中の基本操作

## 5-1　ペンで書く

ペンを選択して、教材上に書き込みます。

授業中の説明や板書は、基本的に **板書レイヤー** に書き込みます。

## 5-2　よく使うペンを追加する

授業でよく使う色や太さのペンは、あらかじめ追加しておくと便利です。

!!! note "掲載予定の画面"
    - ペンの種類を選択する画面
    - ペンを追加する操作画面

## 5-3　手書きした線を消す

ペンで書いた線は、消しゴムを使用して消します。

## 5-4　図形・画像・文字などを削除する

図形や画像、文字などは、消しゴムでは削除できません。

1. **選択**ツールを選びます。
2. 削除したい図形・画像・文字を選択します。
3. 削除します。

!!! warning "図形は「選択」して削除"
    **ペンで書いた線 → 消しゴム**  
    **図形・画像・文字 → 選択して削除**

## 5-5　ページを操作する

授業中に必要な範囲で、ページの移動・追加・削除を行います。

## 5-6　拡大・縮小する

教材の細部を確認するときなどは、画面を拡大・縮小します。

## 5-7　モニタリングする

モニタリングを使用すると、生徒の学習状況を確認できます。

- 生徒の状況を一覧で確認する
- 特定の生徒の画面を確認する
- 生徒の書き込み状況を確認する

!!! note "掲載予定の画面"
    公開版のモニタリング画面では、生徒名を「生徒01」「生徒02」などのダミー表示にします。
