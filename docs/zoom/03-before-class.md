# 授業開始前に確認する

遠隔授業を始める前に、受信校の入室状況と画面表示を確認します。

## 1　受信校が入室しているか確認する

受信校は、原則として各校でZoomミーティングに入室します。

受信校がまだ入室していない場合は、必要に応じて**Neat Pulseから受信校のNeat端末を遠隔操作して、ミーティングに参加させます。**

[Neat Pulseの遠隔操作を確認する](../neat-pulse/){ .md-button }

---

## 2　左右の画面を確認する

受信校の2画面に、授業で使用する映像が正しく表示されていることを確認します。

基本は、次のいずれかです。

- **スピーカービュー ＋ スピーカービュー**
- **スピーカービュー ＋ 共有資料**

必要に応じて、ピン留めやスポットライトを設定します。

[受信校のビュー設定を確認する](02-receiver-view/){ .md-button }

---

## 3　授業開始前の最終確認

授業を始める前に、次の点を確認します。

- 受信校がZoomミーティングに入室している
- 配信教員の映像が意図した画面に表示されている
- 画面共有を使用する場合、共有資料が正しく表示されている
- 受信校のセルフビューが表示されていない

問題がなければ、授業を開始します。
