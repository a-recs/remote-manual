# 0　管理画面・メニュー早見表

MetaMoJi ClassRoom 3の管理作業では、まず**管理ツールのどの画面・メニューを使うか**を確認します。

このページでは、A-RECSの運用で使う機会が多いメニューを「やりたいこと」から探せるように整理しています。

[管理ツールを開く](https://api-classroom.metamoji.com/mmjmanage/tools/ja/login.html){ .md-button .md-button--primary target="_blank" }

---

## 団体管理トップ

### 画面上部の表示

**トップ ＞ 団体管理**

団体管理トップには、学校・ユーザー・年度などを管理するメニューが並んでいます。

### どのメニューを使う？

| やりたいこと | 選ぶメニュー |
|---|---|
| 教員・生徒を確認、追加、変更する | **ユーザー一覧** |
| 教員・生徒をExcel／CSVでまとめて登録する | **ユーザー一括登録** |
| 学校を確認、追加、変更する | **学校一覧** |
| 複数の学校をまとめて登録する | **学校一括登録** |
| 登録済みユーザーを学校に所属させる | **ユーザーを学校に振り分け** |
| 新しい年度を登録する | **年度の登録** |
| 団体全体の年度を切り替える | **年度の切り替え** |
| 学校・年度・クラス・ユーザーをまとめて更新する | **全項目一括登録** |
| 学校別の利用状況を確認する | **利用状況** |
| 月ごとの利用状況を確認する | **利用状況推移** |
| 管理ツールの操作履歴を確認する | **操作ログ** |
| 利用できる機能を設定する | **カスタマイズ設定** |
| 管理者のID・パスワード等を変更する | **ビルトイン管理ユーザーの設定** |
| 誤って削除したデータを戻す | **データの復元** |

!!! tip "迷ったらここから"
    年度初めの作業では、主に**［年度の登録］［全項目一括登録］［年度の切り替え］**を使用します。新しい学校やユーザーを個別に追加するときは、**［学校一覧］［ユーザー一覧］［ユーザーを学校に振り分け］**を使用します。

## 学校を確認・編集する

### 開き方

**団体管理トップ →［学校一覧］**

### 画面上部の表示

**トップ ＞ 学校一覧**

学校一覧では、団体に登録されている学校を確認します。

| 項目 | 確認する内容 |
|---|---|
| **正式学校名** | 登録されている正式な学校名 |
| **学校名** | MetaMoJi上で使用する学校名 |
| **学校コード** | 学校に割り当てられているコード |
| **鉛筆アイコン** | 対象校の登録内容を編集する |

### こんなときに使う

- 新しい受信校を登録・確認するとき
- 学校名や学校コードを確認するとき
- 登録済みの学校情報を変更するとき

!!! warning "公開用スクリーンショット"
    実際の学校名・学校コードなど、公開に適さない情報は掲載しません。本マニュアルでは**A高校・B高校**などのダミー情報に置き換えます。

## ユーザーを追加・変更する

### 開き方

**団体管理トップ →［ユーザー一覧］**

ユーザー一覧では、先生・生徒の登録内容を確認し、新規登録・変更・削除を行います。

まとまった人数を登録する場合は、**［ユーザー一括登録］**を使用します。

### 登録後に忘れないこと

ユーザーを団体へ登録しただけでは、利用する学校への所属設定が必要な場合があります。

**団体管理トップ →［ユーザーを学校に振り分け］**

から、対象の学校へ所属させます。

!!! tip "複数校を担当する教員"
    配信担当教員が複数の受信校を担当する場合は、必要な学校すべてに所属しているか確認します。

## 新年度を登録する

### 開き方

**団体管理トップ →［年度の登録］**

新しい年度を作成します。

次年度を事前に準備するときは、準備が完了するまで非公開として設定することができます。

[年度更新の手順を見る](02-annual-renewal.md){ .md-button }

---

## 年度更新をまとめて行う

### 開き方

**団体管理トップ →［全項目一括登録］**

Excel／CSVファイルを使って、**学校・年度・クラス・ユーザー等をまとめて登録・変更**するときに使用します。

A-RECSでは、年度更新時の進級・卒業／転出・新入生・クラス替えなどをまとめて処理するときに使用します。

[年度更新の手順を見る](02-annual-renewal.md){ .md-button }

---

## 年度を切り替える

### 開き方

**団体管理トップ →［年度の切り替え］**

団体全体の年度を新年度へ切り替えます。

!!! danger "最後に行う操作"
    団体管理から年度を切り替えると、**所属するすべての学校に反映されます。** 新年度のユーザー・クラス等を確認してから実行します。

---

## 年度途中にユーザーを追加するとき

### 基本の流れ

1. **［ユーザー一覧］**でユーザーを登録する
2. **［ユーザーを学校に振り分け］**で対象校に所属させる
3. 学校側で必要なクラスに所属させる
4. ログイン情報・QRコードを準備する
5. 実際にログインできることを確認する

[年度途中の変更を見る](03-midyear-management.md){ .md-button }

## 管理画面の役割を覚える

大きく分けると、管理ツールでは次のように考えると分かりやすくなります。

- **団体管理**：学校、ユーザー、年度など、団体全体の土台を管理する
- **学校管理**：年度ごとのクラス、クラス分け、担当教員など、学校単位の設定を行う

初期設定では、団体管理側の設定を行ったあと、学校管理側でクラスを準備します。
