# MetaMoJi ClassRoom 管理者編

MetaMoJi ClassRoom 3を利用するための、**年度・学校・ユーザー・クラスの管理方法**をまとめています。

本マニュアルでは、公式マニュアルのすべての機能を掲載するのではなく、遠隔授業の運用で管理者が確認する機会の多い作業を中心に説明します。

[管理ツールを開く](https://api-classroom.metamoji.com/mmjmanage/tools/ja/login.html){ .md-button .md-button--primary target="_blank" }

[管理画面・メニュー早見表を見る](00-menu-guide.md){ .md-button }

## まず「どのメニューを使うか」を確認

管理ツールを開いたら、最初に**やりたい作業に対応するメニュー**を確認します。

| やりたいこと | 団体管理で選ぶメニュー |
|---|---|
| 学校を確認・追加・変更する | **学校一覧** |
| 教員・生徒を確認・追加・変更する | **ユーザー一覧** |
| ユーザーを学校に所属させる | **ユーザーを学校に振り分け** |
| 新年度を登録する | **年度の登録** |
| 年度更新をまとめて行う | **全項目一括登録** |
| 団体全体の年度を切り替える | **年度の切り替え** |
| 誤って削除したデータを戻す | **データの復元** |

!!! info "管理画面の見方"
    **［トップ ＞ 団体管理］**が団体全体の設定を行う入口です。学校・ユーザー・年度などの設定は、ここから目的のメニューを選びます。

---

## 管理者が行う作業

管理作業は、大きく3つに分かれます。

| 場面 | 主な作業 |
|---|---|
| **[新規導入・学校追加時](01-initial-setup.md)** | 年度・学校・ユーザー・クラスを設定 |
| **[年度末～年度初め](02-annual-renewal.md)** | 進級・卒業／転出・新入生・クラス替え、ログイン用QRコードの配布 |
| **[年度途中](03-midyear-management.md)** | 教員・生徒の追加、所属変更、パスワード再設定 |

!!! tip "毎年確認するページ"
    通常、毎年度確認するのは**「年度更新」**です。新しい受信校を追加するときは、あわせて**「初回導入・初期設定」**を確認します。

## 団体管理者と学校管理者

MetaMoJi ClassRoom 3では、付与された権限によって操作できる範囲が異なります。

### 団体管理者

団体全体に関する設定を行います。

- 年度の登録
- 学校の登録
- ユーザーの登録
- ユーザーの学校への振り分け
- 団体全体の年度切替
- 学校管理に関する設定

### 学校管理者

担当する学校に関する設定を行います。

- クラスの登録
- 生徒のクラス分け
- 先生の担当クラス設定
- 学校内のユーザー・クラス管理
- 学校単位の年度切替（必要な場合）

!!! note "設定の基本的な順番"
    初期設定では、まず**団体管理者が学校・年度・ユーザー等を準備**し、その後、**学校管理者がクラス登録・クラス分け**を行います。

## 公開用マニュアルでの注意

管理画面には個人情報やログイン情報が表示されます。

スクリーンショットを掲載するときは、次の情報を公開しないようにします。

- 実際の学校名
- 氏名
- ユーザーID
- 団体ID
- パスワード
- QRコード
- その他、個人や組織を特定できる情報

本マニュアルでは、必要に応じて**「A高校」「先生A」「生徒A」などのダミー情報**を使用します。
