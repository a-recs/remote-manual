# はじめに

## ideaCam S1 Proとは

BenQ ideaCam S1 Proは、PCにUSBで接続するWebカメラです。正面から人物を映す一般的なWebカメラの使い方に加え、モニターに取り付けたまま下向きにして机上を映したり、スタンドから外して手で持ったりできます。付属の磁石式拡大レンズを使うと、小さな被写体の細部も映せます。

## 主な付属品

| 付属品 | 役割 |
| --- | --- |
| スタンド（ウェブカメラマウント） | 本体をモニター上部に固定し、カメラの向きを調整できるようにします。 |
| 15倍拡大レンズ | 小さな被写体を近くから撮影し、細部を映します。 |
| ワイヤレスリモコンと電池 | EnSpireでズームやフリーズなどを操作します。Web版のアプリを立ち上げる必要があります。 |
| USBレシーバー | PCのUSBポートに差し込み、ワイヤレスリモコンからの操作を受け取ります。 |

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） 付属品を並べ、リモコンと小型USBレシーバーの位置が分かる写真。 -->

## 通常撮影と拡大撮影

| 撮影方法 | 遠隔授業での用途 |
| --- | --- |
| 通常撮影 | 本体のレンズで、教員の顔、机上の教材全体、紙に書き込む手元などを映します。 |
| 拡大撮影 | 付属レンズで、印刷物の模様や小さな部品の表面など、被写体の一部分を近くから映します。 |

授業では、まず通常撮影で教材の全体を示してから、細部を見せたい場面で拡大撮影を使うと、受講者がどの部分を見ているか把握しやすくなります。

付属品と撮影方法はBenQの公式資料に基づいています。 [ideaCam S1シリーズ ユーザーマニュアル（日本語PDF）](https://esupportdownload.benq.com/esupport/CAMERA%20DEVICE/UserManual/ideaCam%20S1/UM_JA_231109153048.pdf)

次に、[基本操作](operation.md)で取り付けと撮影を確認してください。
