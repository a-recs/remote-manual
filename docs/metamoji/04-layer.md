# 4　レイヤーを理解する

授業ノートでは、教材や先生の書き込みなどをレイヤーに分けて管理します。

遠隔授業を行ううえでは、まず次の3つを理解しておきます。

| レイヤー | 生徒から見える | 生徒が編集 | 主な用途 |
|---|:---:|:---:|---|
| **先生レイヤー** | 原則として見えない | できない | 先生だけのメモや解答など |
| **板書レイヤー** | 見える | できない | 授業中の説明・板書 |
| **教材レイヤー** | 見える | できない | PDFなど授業の土台となる教材 |

!!! tip "覚え方"
    **教材レイヤー＝授業前に準備した教材**  
    **板書レイヤー＝授業中に先生が教材の上に書き足すもの**  
    **先生レイヤー＝先生だけが見るもの**

## 教材レイヤーと板書レイヤーの違い

例えば、PDFで作成した問題文や図は **教材レイヤー** に置かれます。

授業中に先生が書き込む途中式、赤丸、補足説明などは **板書レイヤー** に書き込みます。

生徒自身の書き込みは **学習レイヤー** に記録されます。

!!! note "掲載予定の画面"
    レイヤー一覧（先生レイヤー・板書レイヤー・教材レイヤー）が表示されている画面を掲載します。
