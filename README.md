# 遠隔教育運営マニュアル

遠隔授業の準備・配信・運営に必要な操作を、必要なときにすぐ確認できるようにまとめたWebマニュアルです。

**公開サイト**  
https://a-recs.github.io/remote-manual/

## 掲載内容

現在、次の内容を掲載しています。

- **授業配信の流れ**
  - 授業前・授業中・授業終了時の基本的な流れ
- **MetaMoJi ClassRoom**
  - 操作編
    - ログイン・学校選択
    - マイボックスとクラスボックス
    - 教材準備・配布
    - レイヤー
    - 授業中の基本操作
  - 管理者編
    - 生徒登録
    - クラス作成
    - クラス所属
    - CSV一括登録
    - QRコード
    - 年度更新
- **Zoom**
  - 遠隔授業で使用する基本操作
- **Neat Pulse**
  - ログイン
  - 端末の状態確認
  - Remote Controlによる遠隔操作
- **ATEM Mini Pro**
  - 配信時に使用する基本操作

## マニュアルの方針

このマニュアルは、機能を網羅することよりも、**遠隔授業を実施する際に必要な操作をすぐ確認できること**を重視しています。

- 操作手順はできるだけ短く整理する
- 画面例は必要な箇所に絞って掲載する
- PC・タブレット・スマートフォンから確認できる構成とする
- ライトモード／ダークモードの両方で読みやすくする
- 画像はクリックまたはタップして拡大確認できるようにする

## 公開用の取扱い

本リポジトリは公開リポジトリです。

実在する学校名・教員名・生徒名・ユーザーID・団体ID・ログイン用QRコード・IPアドレス・MACアドレス・シリアル番号等、公開に適さない情報は掲載しません。

画面例で名称等が必要な場合は、**A高校・B高校・教員A・生徒01**などのダミー情報を使用するか、必要な箇所をぼかして掲載します。
