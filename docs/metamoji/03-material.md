# 3　教材を準備・配布する

## 3-1　教材をPDFで作成する

授業で使用する教材を **PDF形式** で準備します。

教材を作成するソフトウェアは問いません。授業で使用する教材をPDFとして保存してください。

## 3-2　PDF教材をMetaMoJiに読み込む

準備したPDFをMetaMoJi ClassRoomに読み込み、マイボックスに教材を作成します。

!!! note "掲載予定の画面"
    - PDFを読み込む操作画面
    - マイボックスに教材が作成された状態

## 3-3　授業ノートとして配布する

マイボックスで準備した教材を、授業を行うクラスへ授業ノートとして配布します。

1. 現在選択している学校を確認します。
2. 配布するクラスを選択します。
3. 授業ノートとして配布します。
4. クラスボックスに授業ノートが表示されていることを確認します。

!!! warning "学校を確認してください"
    複数校を担当している場合は、配布前に授業を行う学校が正しく選択されていることを確認してください。
