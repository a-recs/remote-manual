# MetaMoJi ClassRoom 管理者編

この管理者編は、**遠隔授業を実施するために必要な設定だけ**をまとめています。

MetaMoJi ClassRoom 3には多くの管理機能がありますが、A-RECSで通常の授業を始めるために使う項目に絞っています。

[管理ツールを開く](https://api-classroom.metamoji.com/mmjmanage/tools/ja/login.html){ .md-button .md-button--primary target="_blank" }

## まず、どの作業？

| 場面 | これだけ行う |
|---|---|
| **[新しい受信校で授業を始める](01-initial-setup.md)** | 学校 → ユーザー → クラス → QRコード → ログイン確認 |
| **[年度更新する](02-annual-renewal.md)** | 新年度 → 名簿・クラス更新 → 年度切替 → QRコード → ログイン確認 |
| **[年度途中で追加・変更する](03-midyear-management.md)** | ユーザー追加 → 学校・クラス所属 → QRコード → ログイン確認 |

!!! tip "迷ったら"
    毎年行うのは、基本的に**「年度更新」**です。新しい受信校が増えた場合だけ**「新しい受信校で授業を始める」**を確認します。

---

## 授業実施のために使う管理メニュー

[必要な管理メニューを見る](00-menu-guide.md){ .md-button }

主に使うのは次のメニューだけです。

### 団体管理

- **学校一覧**
- **ユーザー一覧**
- **ユーザーを学校に振り分け**
- **年度の登録**
- **全項目一括登録**
- **年度の切り替え**

### 学校管理

- **クラス登録**
- **クラス分け・担当教員の設定**
- **クラス別QRコード一覧**

それ以外の管理機能は、通常の授業開始準備では使用しません。必要になった場合はMetaMoJi公式マニュアルを確認します。

---

!!! warning "公開用資料の注意"
    管理画面には学校名・氏名・ユーザーID・QRコードなどが表示されます。公開用スクリーンショットでは、**A高校・先生A・生徒A**などのダミー情報を使用します。
