# 2　年度更新

年度末～年度初めに行う、**進級・卒業／転出・新入生・クラス替え等の更新**をまとめています。

MetaMoJi ClassRoom 3では、年度更新をExcelの一括登録機能を使って行うことができます。

[公式：年度更新ガイドを開く](https://product.metamoji.com/manual/classroom/cr3/document/ja/CR3AnnualRenewalGuide.pdf){ .md-button target="_blank" }

## 年度更新の全体像

団体管理者が団体管理メニューから年度更新する場合は、次の順番で進めます。

1. 新年度を登録する
2. 旧年度の名簿をダウンロードする
3. Excelファイルを編集する
4. 編集したExcelファイルをアップロードする
5. 登録内容を確認する
6. 年度を切り替える
7. ログイン・クラス表示を確認する

!!! danger "年度切替は最後に行う"
    団体管理メニューから年度を切り替えると、**団体内すべての学校の年度が切り替わり、元に戻すことはできません。**

    必ず、登録内容を確認してから年度を切り替えます。

---

## 2-1　年度更新に必要な権限

年度更新は、団体管理者または学校管理者が行います。

ただし、次の点に注意します。

- **新年度そのものを登録できるのは団体管理者のみ**です。
- 団体管理者は、団体管理メニューから団体内の学校をまとめて更新できます。
- 学校管理者が年度更新する場合は、団体管理者側の設定でユーザー登録・削除が許可されている必要があります。
- 学校管理者が更新する場合も、事前に団体管理者が新年度を登録しておく必要があります。

---

## 2-2　新年度を登録する

まず、団体管理者が新年度を登録します。

準備中は**［公開する］をオフ**にしておくことで、団体管理者以外に新年度を表示せずに準備できます。

### 確認すること

- 年度名が正しい
- 対象となる年度を間違えていない
- 公開／非公開の設定が意図どおりになっている

---

## 2-3　旧年度の名簿をダウンロードする

年度更新に使用するExcelファイルをダウンロードします。

団体管理メニューから年度更新する場合は、旧年度の登録情報を元にファイルを取得します。

!!! warning "元ファイルを保存する"
    ダウンロードしたファイルは、編集前の状態を残すため、**元データとして別名保存**しておくことをおすすめします。

---

## 2-4　Excelファイルを編集する

年度更新用のExcelでは、主に次の作業を行います。

### 卒業生・転出生を設定する

卒業・転出するユーザーは、**［卒業・転出なら1］に半角数字の「1」**を入力します。

卒業・転出に設定したユーザーは、マイボックスと過去のクラスボックスを閲覧できますが、ノート・授業ノートの編集や新規ノートの作成はできなくなります。

### 在校生を進級・クラス替えする

進級・クラス替えをする在校生について、

- ［年度］を新年度へ変更
- ［クラス名］を新しいクラスへ変更

します。

### 新入生を登録する

新入生について、必要なユーザー情報を追加します。

主な項目は次のとおりです。

- ユーザーID
- ユーザー名
- パスワード
- 正式学校名
- 学校名
- 年度
- クラス名

その他の項目は必要に応じて入力します。

!!! warning "公開用資料ではダミー情報を使う"
    年度更新Excelには氏名・ユーザーID等が含まれます。スクリーンショットを作成するときは、実在する情報を使用しないでください。

---

## 2-5　編集したExcelをアップロードする

Excelの編集が終わったら、管理ツールへ戻り、編集したファイルをアップロードします。

エラーが表示された場合は、表示されたメッセージを確認し、Excelを修正して再度アップロードします。

### エラーが出たら確認すること

- 必須項目が空欄になっていないか
- 年度名・学校名・クラス名が登録済みの名称と一致しているか
- 数値を入力する欄に全角文字を入れていないか
- 同じユーザーIDが重複していないか

---

## 2-6　登録内容を確認する

年度を切り替える前に、新年度の登録内容を確認します。

### チェックリスト

- [ ] 新年度が登録されている
- [ ] 新しいクラスが登録されている
- [ ] 在校生が正しい年度・クラスへ進級している
- [ ] クラス替えが反映されている
- [ ] 卒業・転出生の設定が正しい
- [ ] 新入生が登録されている
- [ ] 担当教員が正しい

!!! tip "年度切替前に確認"
    ここで問題があれば、年度を切り替える前に修正します。

---

## 2-7　年度を切り替える

すべての登録内容を確認したら、新年度へ切り替えます。

### 団体管理メニューから切り替える場合

団体内の**すべての学校が一斉に新年度へ切り替わります。**

!!! danger "元に戻せません"
    団体単位の年度切替は元に戻すことができません。対象年度・各学校の登録状況を再確認してから実行します。

### 学校単位で切り替える場合

学校ごとに年度を切り替えることもできます。

団体管理者から学校単位で切り替えるよう指示された場合などに使用します。団体管理者による年度切替に従う場合は、学校側での切替作業は不要です。

---

## 2-8　年度更新後に確認する

年度切替後、任意の先生・生徒アカウントでログインし、新年度の情報が正しく表示されるか確認します。

### チェックリスト

- [ ] ログインできる
- [ ] 新年度が表示される
- [ ] 新年度のクラスが表示される
- [ ] 担当教員が正しい
- [ ] 生徒が正しいクラスに所属している
- [ ] 過去年度のクラスを確認できる

---

## 過去のクラスボックスはどうなる？

### 進級した生徒

新年度のクラスボックスが利用できるようになります。

旧年度のクラスボックスは**過去のクラスボックス**へ移動し、これまでの学習内容を開いて振り返ることができます。

### 卒業・転出した生徒

マイボックスと過去のクラスボックスを閲覧できます。

ただし、ノート・授業ノートは閲覧のみとなり、編集や新規ノート作成はできません。

---

## 年度更新チェックリスト

### 更新前

- [ ] 新年度を登録した
- [ ] 旧年度のExcelをダウンロードした
- [ ] 編集前ファイルをバックアップした

### Excel編集

- [ ] 卒業生を設定した
- [ ] 転出生を設定した
- [ ] 在校生を進級させた
- [ ] クラス替えを反映した
- [ ] 新入生を登録した
- [ ] 担当教員を確認した

### アップロード後

- [ ] エラーがない
- [ ] 新年度のクラスを確認した
- [ ] 生徒の所属を確認した
- [ ] 担当教員を確認した

### 年度切替後

- [ ] 先生アカウントで確認した
- [ ] 生徒アカウントで確認した
- [ ] 新年度のクラスが表示されることを確認した

すべて確認できたら、年度更新は完了です。
