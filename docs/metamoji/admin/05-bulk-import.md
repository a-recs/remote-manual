# CSVで一括登録する

生徒数が多い場合は、ブラウザで1件ずつ登録する代わりに、**CSVを使ってまとめて登録**できます。

MetaMoJi ClassRoom 3では、Excel形式またはCSV形式のファイルを使って、**ユーザー登録・学校への振り分け・年度・クラス・クラス分け**を一括で登録できます。

このページでは、遠隔授業で必要な

**生徒登録 → 学校所属 → クラス作成 → クラス所属**

をまとめて行う方法に絞って説明します。

!!! tip "個別登録との使い分け"
    数人だけ追加する場合は、ブラウザから個別に登録する方が簡単です。複数の生徒・クラスをまとめて準備するときは、一括登録を使うと作業を減らせます。

---

## 1　一括登録の画面を開く

### 開く場所

**トップ ＞ 団体管理 ＞ 全項目一括登録**

一括登録に使用するファイルを準備します。

最初は、画面からExcel形式のファイルをダウンロードして、**項目名と並びを確認してから作成する**のがおすすめです。

CSVを使用する場合も、同じ項目に合わせて作成します。

---

## 2　登録する内容を入力する

生徒登録からクラス所属までまとめて行う場合は、主に次の項目を使用します。

| 項目 | 入力する内容 |
|---|---|
| ユーザーID | 生徒・教員のログインID |
| ユーザー名 | 生徒名・教員名 |
| パスワード | 初期パスワード |
| 正式学校名 | 対象となる学校の正式名称 |
| 年度 | 登録する年度 |
| クラス名 | 所属させる授業用クラス |
| 先生なら1 | 教員の場合は `1` |
| クラス管理者なら1 | 担当教員として設定する場合は `1` |

!!! note "学校を新しく登録する場合"
    学校そのものも同時に新規登録する場合は、**学校名**など学校登録に必要な項目も入力します。すでに登録済みの学校へ生徒を追加する場合は、既存の正式学校名を使用します。

### 生徒の場合

生徒は、ユーザーID・ユーザー名・パスワード・正式学校名・年度・クラス名を入力します。

### 担当教員の場合

担当教員は、上記に加えて**［先生なら1］**と**［クラス管理者なら1］**に `1` を入力します。

!!! info "複数クラスに所属する場合"
    同じユーザーを複数のクラスに所属させる場合は、同じユーザーIDを複数行に記載できます。ユーザー名などの任意情報を入力するときは、そのユーザーIDが最初に出てくる行に入力します。

---

## 3　CSVをアップロードする

作成したCSVを一括登録画面からアップロードします。

エラーが表示された場合は、表示された内容を確認してCSVを修正し、再度アップロードします。

---

## 4　登録内容を確認する

アップロード後、次の内容が登録されていることを確認します。

- 生徒・担当教員が登録されている
- 対象校に所属している
- 授業用クラスが作成されている
- 生徒・担当教員が正しいクラスに所属している

**ここまでできれば、一括登録は完了です。**
