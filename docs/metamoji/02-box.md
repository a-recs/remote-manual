# 2　マイボックスとクラスボックス

## 2-1　マイボックスとクラスボックスの違い

MetaMoJi ClassRoomでは、主に**マイボックス**と**クラスボックス**を使用します。

|  | マイボックス | クラスボックス |
|---|---|---|
| 主な用途 | 教材を準備・管理する | 授業で教材を使用する |
| 主な利用者 | 教員本人 | そのクラスの教員・生徒 |
| 遠隔授業での使い方 | PDF教材を読み込み、授業の準備をする | 配布された授業ノートを開いて使用する |

> **マイボックスで教材を準備し、授業ノートとしてクラスボックスへ配布します。**

## 2-2　マイボックス

マイボックスは、**教員個人の教材を準備・管理する場所**です。

複数の学校を担当している場合でも、マイボックスは共通して利用します。

### フォルダを使って教材を整理する

教材が増えてくると目的の教材を探しにくくなるため、必要に応じてフォルダを作成して整理します。

フォルダ構成は一律に決めず、**担当する学校数や教科の特性、教材の使い方に応じて管理しやすい方法を選択します。**

### 学校ごとに整理する例

```text
マイボックス
├─ A高校
├─ B高校
└─ 共通教材
```

複数校で異なる教材を使用する場合などに向いています。

### 単元ごとに整理する例

```text
マイボックス
├─ 01_力学
├─ 02_熱
├─ 03_波動
└─ 04_電磁気
```

同じ教材を複数校で利用する場合などに向いています。

### 授業回ごとに整理する例

```text
マイボックス
├─ 01_第1回
├─ 02_第2回
├─ 03_第3回
└─ 04_第4回
```

授業の順番に沿って教材を管理したい場合に向いています。

!!! tip "ポイント"
    フォルダの作り方に決まりはありません。自分が必要な教材を探しやすい方法で整理してください。

> **画像掲載予定**
> - マイボックス全体
> - フォルダを作成する場所
> - フォルダ整理後の例

## 2-3　クラスボックス

クラスボックスは、**クラスごとに教材や授業ノートを使用する場所**です。

教員が授業ノートを配布すると、指定したクラスのクラスボックスに表示されます。

生徒は、自分が所属するクラスのクラスボックスから授業ノートを開きます。

> **画像掲載予定**
> - クラスボックス一覧
> - 授業ノートが表示されている状態

### クラスボックスも必要に応じて整理する

クラスボックス内の教材が増えてきた場合は、フォルダを作成して整理します。

```text
クラスボックス
├─ 01_1学期
├─ 02_2学期
└─ 03_3学期
```

または、単元ごとに整理する方法もあります。

```text
クラスボックス
├─ 01_力学
├─ 02_熱
├─ 03_波動
└─ 04_電磁気
```

クラスボックスは生徒も利用するため、**生徒が授業ノートを見つけやすい構成**を意識します。

## 2-4　使い分けの基本

**マイボックス**は教材を作る・準備する・整理する場所、**クラスボックス**は生徒と授業で使用する場所です。

**マイボックスで教材を準備 → 授業ノートとして配布 → クラスボックスで授業**
