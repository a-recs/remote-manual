# ATEM Software Control

ATEM Software Controlは、ATEM Mini Proをパソコン上から操作するためのソフトウェアです。

![ATEM Software Control の全体画面](../images/Atem/ATEMSoft.png)

*ATEM Software Control の全体画面*

## 基本的な映像切替

ATEM Software Controlでは、現在出力している映像と次に出力する映像を確認しながら、映像を切り替えることができます。

### プログラム（PROGRAM）

プログラムは、**現在実際に出力されている映像**です。

赤く点灯しているボタンが、現在プログラムとして出力されている映像を示します。
別の入力を直接選択すると、その映像へすぐに切り替わります。

| ボタン | 内容 |
| --- | --- |
| CAM1～CAM4 | HDMI入力映像 |
| BLK | 黒画面 |
| COL1 / COL2 | ATEM内部で設定した単色 |
| BARS | 映像確認用のカラーバー |
| MP1 | Media Player 1に登録した静止画 |

!!! note
    **MP1**は、ATEM Mini Pro本体の**STILL**ボタンに相当します。

### プレビュー（PREVIEW）

プレビューは、**次に出力する映像をあらかじめ選択する**ために使用します。

緑色に点灯しているボタンが、現在選択されているプレビュー映像です。

プレビューで映像を選択しただけでは、現在出力されているプログラム映像は変わりません。
その後、CUT、AUTO、トランジション・フェーダーなどを操作することで、プレビュー映像をプログラムへ切り替えます。

選択できる映像ソースは、プログラムと同じです。

---

### ネクスト・トランジション（NEXT TRANSITION）

ネクスト・トランジションでは、**次の切り替え操作で何を切り替えるか**を指定します。

#### BKGD

背景映像を切り替えます。

CAM1からCAM2へ切り替えるなど、通常の映像切り替えではBKGDを使用します。

#### KEY1～KEY4

各キー合成を、次のトランジションに含めるかを指定します。

例えばKEY1でクロマキー合成した教員映像を表示している場合、BKGDのみを選択すると、**教員映像を残したまま背景映像だけを切り替える**ことができます。

#### ON AIR

各キーが現在プログラムに出力されているかを示します。

ON AIRを操作することで、キー合成を直接表示・非表示にすることもできます。

!!! tip
    クロマキー合成した教員を表示したまま教材だけを切り替える場合は、**BKGDのみを選択**します。

---

### トランジションスタイル

プログラムからプレビューへ、**どのような効果で映像を切り替えるか**を設定します。

| ボタン | 内容 |
| --- | --- |
| MIX | 2つの映像を徐々に重ねながら切り替える |
| DIP | 一度別の色や映像を経由して切り替える |
| WIPE | 画面を拭き取るような動きで切り替える |
| DVE | 映像を移動・縮小するなどして切り替える |
| STING | アニメーションなどを利用した特殊な切り替え |

遠隔授業では、まずは**MIXを基本の切り替え方法**として使用すると操作しやすくなります。

---

### CUT / AUTO / PREV TRANS

#### CUT

プレビューで選択した映像へ**瞬時に切り替えます**。

ATEM Mini Pro本体のCUTボタンと同じ役割です。

#### AUTO

選択しているトランジションスタイルを使用し、設定された時間で自動的に映像を切り替えます。

例えばMIXを選択してAUTOを押すと、現在の映像から次の映像へ徐々に切り替わります。

#### PREV TRANS

設定したトランジションの動きを、実際にプログラムへ出力する前に確認するときに使用します。

WIPEやDVEなどの動きを確認するときに便利です。

#### レート

AUTOトランジションにかける時間を設定します。

表示される値はフレームを基準としており、実際の時間は使用している映像フォーマットによって異なります。

---

### トランジション・フェーダー

画面中央下部のフェーダーを操作すると、トランジションを**手動で進める**ことができます。

CUTは瞬時に切り替え、AUTOは設定した時間で自動的に切り替えるのに対して、フェーダーでは操作者が動かす速度に合わせて切り替えることができます。

遠隔授業ではCUTやAUTOを使用する場面が多いため、必要に応じて使用します。

---

### DSK1（Downstream Keyer）

DSKは、完成したプログラム映像の上に、さらにロゴやテロップなどを重ねるための機能です。

例えば、教材映像やクロマキー合成した教員映像の上に、A-RECSのロゴなどを表示することができます。

#### ON AIR

DSKを直接表示・非表示にします。

#### AUTO

設定したレートでDSKを表示・非表示にします。

#### TIE

DSKを通常のトランジション操作と連動させます。

#### レート

DSKのAUTO動作にかける時間を設定します。

---

### FTB（Fade To Black）

FTBは、現在のプログラム映像全体を徐々に黒画面へ切り替える機能です。

もう一度操作すると、黒画面からプログラム映像へ戻ります。

授業開始前や授業終了時など、画面全体をまとめて黒くしたいときに使用できます。

レートでは、黒画面へ切り替わるまでの時間を設定します。

---

## 基本的な操作の流れ

Software Controlで映像を切り替える場合は、次の流れで操作します。

1. **PREVIEW**で次に出す映像を選択する
2. **NEXT TRANSITION**で切り替える対象を選択する
3. **Transition Style**で切り替え方法を選択する
4. **CUT / AUTO / トランジション・フェーダー**で切り替える
