# EnSpire Web版

EnSpire Web版では、ブラウザーでideaCamの映像を表示し、ワイヤレスリモコンで画角やピントなどを操作できます。先に[基本操作](operation.md)の手順でideaCamをPCに接続してください。

## 1. EnSpire Web版を開く

インターネットに接続したPCで、ChromeまたはMicrosoft Edgeから [EnSpire Web版](https://enspire.benq.com/) を開きます。

!!! note "組織の利用ルールを確認する"
    所内PCへのソフトウェアのインストールには、許可が必要な場合があります。Web版を使う場合も、外部サービスの利用、アカウント、カメラ・マイクの許可に関する組織のルールに従ってください。

## 2. ログインする

ログイン画面でGoogleアカウントを使う方法を選び、組織で利用が認められているアカウントでログインします。BenQの公式マニュアルには、新規アカウントを作成して進む方法も案内されています。作成前に組織のルールを確認してください。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） ログイン方法の選択画面。氏名やメールアドレスが表示されていない状態。 -->

## 3. ideaCamの映像を表示する

1. ブラウザーからカメラとマイクへのアクセスを求められたら、組織のルールに従って許可します。
2. **［Settings（設定）］→［Source Settings（ソース設定）］** を開き、カメラの一覧でideaCamを選びます。
3. ideaCamの前で手を動かし、EnSpireの画面に動きが表示されることを確かめます。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） カメラ・マイクの許可画面とソース設定でideaCamを選ぶ画面。 -->

## 4. USBレシーバーを接続する

1. リモコンの電池カバーを開け、収納部にある小型のUSBレシーバーを取り出します。
2. リモコンに電池を入れるときは、電池ホルダーのプラス・マイナス表示に合わせ、カバーを閉めます。
3. レシーバーを、カメラ本体を接続したPCの空いている **USB Type-A** ポートに差し込みます。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） リモコンの電池カバー内のレシーバー収納部と、PCへの差し込み位置。 -->

## 5. ワイヤレスリモコンを試す

EnSpireで映像を表示したまま、リモコンの外周にあるズームリングを少し回します。画面の映像が拡大・縮小することを確かめます。ボタンを押したときのステータスライトも確認してください。BenQの説明書では、通常は白く光り、電池残量が少ないときは赤く光ると案内しています。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） リモコン上面と、ズームリング、AF/MF切替、フォーカス、フリーズの位置。 -->

## 6. ズーム・ピント・フリーズを使う

| 機能 | リモコンでの操作 |
| --- | --- |
| ズーム | 外周のリングを回して拡大・縮小します。教材の細部を見せた後は、プレビューを見ながら全体が映る状態に戻します。 |
| AF／MF | **AF/MF切替** ボタンを押します。AFは自動でピントを合わせるモード、MFは手動でピントを調整するモードです。MFに切り替えたら、フォーカスボタンを使い、プレビューで文字の輪郭を見ながら調整します。 |
| フリーズ | **フリーズ** ボタンを押して映像を止めます。もう一度押し、手を動かすと映像も動くことを確かめます。 |

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） Web版の機能表示、AF/MFの切り替え前後とフリーズ中の表示。 -->

## 7. リモコンが反応しないとき

1. EnSpire Web版にログイン済みで、画面上のボタンで映像を操作できることを確認します。
2. デスクトップ版のEnSpireが開いていれば終了し、Web版で再度試します。BenQはWeb版とデスクトップ版の同時使用を避けるよう案内しています。
3. リモコン用のUSBレシーバーを一度抜いて同じPCに差し直し、ズームリングを回して映像が変化するか確認します。
4. リモコンのボタンを押してライトを確認します。光らない場合は電池の向きと残量を確認し、赤く光る場合は電池を交換します。改善しなければ、試した手順を機器の管理担当者に伝えてください。

!!! info "現場で確認した復旧例"
    Web画面では操作できても、リモコンだけ反応しないことがありました。USBレシーバーを接続し直すと操作できるようになりました。この事例の原因は未確認です。
