# 6　困ったとき

授業中に問題が起きたときは、まず下の早見表から症状に近いものを確認します。

---

## 6-1　トラブル早見表

| 症状 | まず確認すること | 対応 |
|---|---|---|
| 学校が表示されない | ログイン状態 | 一度ログインし直します。表示されない場合は、MetaMoJi管理者へ確認します。 |
| クラスが表示されない | 選択している学校 | 授業を行う学校を選択し直します。 |
| 授業ノートが見つからない | クラスボックス | 配布先のクラスボックスとフォルダを確認します。 |
| 生徒側に教材が表示されない | 配布先・通信状態 | 配布先のクラスを確認し、生徒側で授業ノートを開き直します。 |
| 先生の書き込みが生徒側に見えない | レイヤー | **板書レイヤー**に書き込んでいるか確認します。 |
| 生徒の書き込みが確認できない | モニタリング・通信状態 | モニタリングで参加状況を確認します。 |
| 手書きの線を消せない | 消しゴム | 消しゴムを使用します。 |
| 図形・画像・文字を消せない | 選択ツール | 対象を選択して削除します。 |
| PDFの表示がおかしい | 元のPDF | PDFを確認し、必要に応じて作り直して読み込みます。 |
| 操作が反映されない・動作が不安定 | 通信状態 | 通信状態を確認し、改善しない場合はアプリの再起動を検討します。 |

---

## 6-2　生徒側に教材が表示されない

まず、**授業ノートを配布したクラス**を確認します。

1. 教員側で、配布先のクラスボックスに授業ノートが表示されているか確認します。
2. 生徒側で、授業ノートを開き直します。
3. 表示されない場合は、インターネット接続を確認します。

!!! warning "同じ教材をすぐに再配布しない"
    原因を確認せず何度も配布すると、同じ授業ノートが複数作成される場合があります。まず現在の配布状況を確認します。

---

## 6-3　先生の書き込みが生徒側に反映されない

最初に **現在のレイヤー**を確認します。

**先生レイヤーは生徒の画面には反映されません。**  
**板書レイヤーは生徒の画面にも反映されます。**

板書レイヤーに切り替えても反映されない場合は、教員側・生徒側の通信状態を確認します。

---

## 6-4　間違ったクラスへ授業ノートを配布した

誤配布に気付いた場合は、**そのまま授業で使用せず、配布先と内容を確認します。**

1. 誤って配布した学校・クラスを確認します。
2. 配布した授業ノートの内容を確認します。
3. 必要に応じてMetaMoJi管理者・運用担当者へ連絡します。
4. 正しいクラスへ改めて配布します。

!!! danger "個人情報等が含まれている場合"
    生徒氏名、成績、個別の指導内容などが含まれている場合は、自己判断だけで処理せず、**所属先の情報セキュリティ・個人情報の取扱手順に従って速やかに報告**します。

---

## 6-5　授業中に解決できない場合

授業中に原因を探し続けるより、**授業への影響を最小限にすることを優先します。**

管理者や運用担当者へ相談するときは、次の情報があると状況を伝えやすくなります。

- どの操作をしたときに問題が起きたか
- 教員側だけか、生徒側でも起きているか
- 表示されているエラーメッセージ
- 使用している端末

!!! tip "エラー画面を残す"
    個人情報や認証情報が写らない範囲で、エラー画面のスクリーンショットを残しておくと原因確認に役立ちます。
