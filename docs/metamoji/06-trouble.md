# 6　困ったとき

授業中に問題が起きた場合は、まず **「学校」「クラス」「レイヤー」「通信状態」** を順番に確認します。

!!! tip "最初に確認する4項目"
    1. 正しいアカウントでログインしているか  
    2. 正しい学校を選択しているか  
    3. 正しいクラス・授業ノートを開いているか  
    4. インターネット接続に問題がないか

---

## 6-1　トラブル早見表

| 症状 | 最初に確認すること | 対応 |
|---|---|---|
| 学校が表示されない | ログインしているアカウント | 一度ログイン情報を確認します。正しいアカウントでも表示されない場合は、MetaMoJi管理者へ確認します。 |
| クラスが表示されない | 現在選択している学校 | 正しい学校へ切り替えます。それでも表示されない場合は、クラス設定・利用権限を管理者へ確認します。 |
| 授業ノートが見つからない | 学校・クラス・フォルダ | 正しい学校とクラスボックスを開いているか確認し、フォルダ内も確認します。 |
| 生徒側に教材が表示されない | 配布先クラス・通信状態 | 教員側のクラスボックスに授業ノートがあるか確認し、生徒側の通信状態とクラスを確認します。 |
| 先生の書き込みが生徒側に見えない | 編集しているレイヤー | 板書（共有）レイヤーに書き込んでいるか確認します。先生レイヤーに書いていないか確認します。 |
| 生徒の書き込みが確認できない | モニタリング・通信状態 | モニタリング／オンライン巡視で参加状況を確認し、生徒が授業ノートを開いているか確認します。 |
| 手書きの線を消せない | 消しゴムを選択しているか | 消しゴムを選択して、手書き線を消します。 |
| 図形・画像・文字を消せない | 選択ツールを使っているか | 対象を選択ツールで選び、削除します。 |
| PDFの表示がおかしい | 読み込み前のPDF | 元のPDFを確認し、必要に応じてPDFを作り直して再度読み込みます。 |
| 操作が反映されない・動作が不安定 | 通信状態 | インターネット接続を確認します。改善しない場合は、授業への影響を確認したうえでアプリの再起動を検討します。 |

---

## 6-2　授業を行う学校が表示されない

### 確認すること

1. 正しいアカウントでログインしているか確認します。
2. 一度ログアウトし、再度ログインします。
3. 学校選択画面を確認します。

それでも学校が表示されない場合は、教員側の操作ではなく、**アカウントや学校の設定**に原因がある可能性があります。

!!! info "解決しない場合"
    MetaMoJi管理者または運用担当者へ、**ログインしているユーザー名と表示されない学校**を伝えて確認します。  
    パスワードやログイン用QRコードそのものは送付しません。

---

## 6-3　クラスが表示されない

まず、**現在選択している学校**を確認します。

複数校を担当している場合、別の学校を選択したままになっていることがあります。

1. 学校名を確認します。
2. 正しい学校へ切り替えます。
3. クラスボックスを開き直します。

それでも表示されない場合は、クラスの設定や利用権限を管理者へ確認します。

---

## 6-4　授業ノートが見つからない

次の順で確認します。

- [ ] 正しい学校を選択している
- [ ] 正しいクラスボックスを開いている
- [ ] 別のフォルダに入っていないか確認した
- [ ] 授業ノートを配布済みである

!!! tip "マイボックスと混同しない"
    準備中の教材は **マイボックス**、配布後に授業で使用する授業ノートは **クラスボックス** から確認します。

---

## 6-5　生徒側に教材が表示されない

### 教員側で確認する

1. 正しい学校・クラスへ配布したか確認します。
2. クラスボックスに授業ノートが表示されているか確認します。
3. 授業ノートを開けるか確認します。

### 生徒側で確認する

1. 正しいアカウントでログインしているか確認します。
2. 正しいクラスボックスを開いているか確認します。
3. インターネット接続を確認します。
4. 必要に応じて画面を開き直します。

!!! warning "すぐに同じ教材を再配布しない"
    原因を確認せず何度も配布すると、同じ授業ノートが複数作成される可能性があります。まず現在の配布状況を確認します。

---

## 6-6　先生の書き込みが生徒側に反映されない

最初に **現在の編集対象レイヤー**を確認します。

授業中の板書を生徒へ見せる場合は、**板書（共有）レイヤー**に書き込みます。

先生レイヤーに書き込んでいる場合、生徒側には通常表示されません。

### 確認手順

1. 編集対象レイヤーを確認します。
2. 板書（共有）レイヤーへ切り替えます。
3. 簡単な線や文字を書き込みます。
4. 生徒側に表示されるか確認します。
5. 表示されない場合は、教員側・生徒側の通信状態を確認します。

---

## 6-7　図形・画像・文字を削除できない

図形・画像・文字は、消しゴムでは削除できません。

1. **選択**ツールを選びます。
2. 削除したいものを選択します。
3. 削除します。

**手書き線 → 消しゴム**  
**図形・画像・文字 → 選択して削除**

---

## 6-8　間違ったクラスへ授業ノートを配布した

誤配布に気付いた場合は、**そのまま授業で使用せず、まず配布先と内容を確認します。**

1. 誤って配布した学校・クラスを確認します。
2. 配布した授業ノートの内容を確認します。
3. 個人情報や他校に見せてはいけない情報が含まれていないか確認します。
4. 必要に応じてMetaMoJi管理者・運用担当者へ連絡します。
5. 正しいクラスへの配布は、配布先を再確認してから行います。

!!! danger "個人情報等が含まれている場合"
    生徒氏名、成績、個別の指導内容など、取り扱いに注意が必要な情報を誤配布した場合は、自己判断だけで処理せず、**所属先の情報セキュリティ・個人情報の取扱手順に従って速やかに報告**します。

---

## 6-9　授業中に解決できない場合

授業を止めて原因を探し続けるより、授業への影響を最小限にすることを優先します。

### 伝えるとよい情報

- 発生した時刻
- 使用している端末
- 選択していた学校・クラス
- どの操作をしたときに問題が起きたか
- 教員側だけか、生徒側でも起きているか
- 表示されているエラーメッセージ

!!! tip "記録を残す"
    個人情報や認証情報が写らない範囲で、エラー画面のスクリーンショットを残しておくと、原因確認に役立ちます。

このトラブル対応表は、実際の遠隔授業で発生した事例をもとに随時追加・更新します。
