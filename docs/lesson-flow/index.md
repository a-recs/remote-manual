# 授業配信の流れ

遠隔授業当日に、**何をどの順番で確認・操作するか**をまとめています。

各機器・アプリの詳しい操作方法は、それぞれのマニュアルを確認してください。

## 授業前

1. **Zoomミーティングを作成する**
   - 授業用のミーティングを作成します。
   - [Zoom](../zoom/)

2. **受信校の入室と画面を確認する**
   - 受信校がZoomミーティングに入室していることを確認します。
   - 左右それぞれの画面に、意図した映像が表示されていることを確認します。
   - 入室していない場合は、必要に応じてNeat Pulseから遠隔操作して参加させます。
   - [Zoom](../zoom/)
   - [Neat Pulse](../neat-pulse/)

3. **ATEM Mini Proの設定を確認する**
   - 授業で使用する設定になっていることを確認します。
   - [ATEM Mini Pro](../atem-mini-pro/)

## 授業中

1. **授業中のMetaMoJiの操作を行う**
   - 教材提示、板書、モニタリングなど、授業に必要な操作を行います。
   - [授業中の基本操作](../metamoji/05-operation.md)

2. **必要に応じてATEM Mini Proで映像を切り替える**
   - 授業場面に応じて、配信する映像を切り替えます。
   - [ATEM Mini Pro](../atem-mini-pro/)

## 授業終了

**Zoomのホストが［全員に対してミーティングを終了］を選択し、授業を終了します。**

[Zoom](../zoom/)
