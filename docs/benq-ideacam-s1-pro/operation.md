# 基本操作

モニターにideaCamを取り付け、Windows標準の「カメラ」アプリで映像を表示します。学校のPCにBenQ専用ソフトをインストールできない場合も、WindowsがideaCamを認識し、「カメラ」アプリの使用が許可されていれば、映像の表示、写真撮影、動画撮影ができます。

## 1. スタンドを取り付ける

1. スタンド（ウェブカメラマウント）をモニター上端の枠に載せます。
2. スタンド前側の先端をモニターの縁に合わせ、後ろ側がモニターの背面に当たるように置きます。
3. 次の手順でスタンドを固定してから、本体を載せます。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） モニター上端と背面にスタンドが接する位置を横から撮影。 -->

## 2. スタンドのロックを操作する

1. スタンドを手で支え、マウントロックを時計回りに少しずつ回します。
2. スタンドがずれなくなったところで止めます。
3. 本体の取り付け用スロットをスタンドの取り付け位置に合わせ、安定して載っていることを確かめます。

!!! warning "ロックを締めすぎない"
    BenQの説明書では、スタンドが固定された時点で回すのを止めるよう案内しています。現場では、固定後に締め込んだ際に異音が確認されました。音がした場合は手を止め、取り付け位置を確認してください。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） マウントロックの位置と時計回りの向き、本体を載せる位置。 -->

## 3. PCにUSB接続する

1. カメラ本体のケーブルをPCの **USB Type-A** ポートに差し込みます。
2. Windowsがカメラを認識するまで待ちます。認識しないときは、カメラのUSBケーブルを一度抜いて差し直します。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） 本体ケーブルをPCのUSB Type-Aポートに接続した状態。 -->

## 4. Windows標準の「カメラ」アプリを起動する

1. Windowsの **［スタート］** を開きます。
2. 「カメラ」と入力し、検索結果の **［カメラ］** アプリを開きます。
3. カメラへのアクセスを求められた場合は、組織の設定に従って許可します。アクセスが管理されている場合は、管理担当者に確認してください。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） スタートメニューで「カメラ」を検索した画面。 -->

## 5. 内蔵WebカメラからideaCamに切り替える

1. 内蔵Webカメラの映像が出ている場合は、画面の **カメラの切り替え** ボタンを押します。カメラが複数ある場合は、ideaCamの映像が出るまで押します。
2. ideaCamを少し傾け、プレビューの向きが変わることを確かめます。切り替えボタンがなく、映像がideaCamのものでもない場合は、USB接続を確認してアプリを開き直します。

## 6. 写真・動画を撮影する

| 撮影 | 操作 |
| --- | --- |
| 写真 | 写真モードを選び、シャッターボタンを押します。 |
| 動画 | ビデオモードを選び、録画ボタンを押します。撮影を終えるときは停止ボタンを押します。 |

撮影後は、画面に表示されるサムネイルから写真や動画を開き、映像と、必要に応じて録音された音声を確認します。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） 写真モード、録画の開始・停止、撮影後のサムネイル。 -->

## 7. 手元を撮影する

1. 見せたい教材を机に置き、プレビューを表示します。
2. スタンドを支えながら、カメラ本体をゆっくり下へ傾けます。
3. 教材と手を動かす範囲が画面に収まるように、カメラの角度と教材の位置を調整します。
4. 教材の向き、文字の読みやすさ、手の影を確認してから撮影します。

<!-- 撮影予定（docs/images/benq-ideacam-s1-pro/） カメラを下に向けた設置写真と、机上の教材を映したプレビュー。 -->

取り付けと接続はBenQ、Windowsでの操作はMicrosoftの公式資料に基づいています。 [BenQユーザーマニュアル（日本語PDF）](https://esupportdownload.benq.com/esupport/CAMERA%20DEVICE/UserManual/ideaCam%20S1/UM_JA_231109153048.pdf) · [Microsoftのカメラアプリ手順](https://support.microsoft.com/ja-jp/windows/hardware/camera/how-to-use-the-windows-camera-app)

ワイヤレスリモコンを使う場合は、[EnSpire Web版](enspire-web.md)に進みます。
