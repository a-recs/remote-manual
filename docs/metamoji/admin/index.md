## このマニュアルで扱わないもの

通常の授業開始に直接必要のない管理機能は掲載しません。

利用状況、操作ログ、カスタマイズ、削除・復元などが必要になった場合は、MetaMoJi公式マニュアルを確認します。

!!! warning "公開用資料の注意"
    管理画面や一括登録ファイルには学校名・氏名・ユーザーID・パスワード・QRコードなどが含まれます。公開用スクリーンショットやCSV例では、**A高校・先生A・生徒A**などのダミー情報を使用します。
