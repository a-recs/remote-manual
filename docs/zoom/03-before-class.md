# 授業開始前に確認する

遠隔授業を始める前に、受信校の入室状況と画面表示を確認します。

!!! tip "受信校のZoom操作はWebコントローラーを優先"
    受信校への遠隔操作が必要な場合は、まず**Zoom RoomsのWebコントローラー**を使用します。

    **Neat Pulseは補助**として、Webコントローラーで対応できない場合や、Neat端末そのものの確認・遠隔操作が必要な場合に使用します。

---

## 1　受信校が入室しているか確認する

受信校は、原則として各校でZoomミーティングに入室します。

受信校の入室状況を遠隔で確認する場合は、**Zoom RoomsのWebコントローラー**を使用します。

[受信校の操作方法を確認する](02-receiver-view/){ .md-button .md-button--primary }

---

## 2　受信校が入室していない場合

受信校がまだ入室しておらず、遠隔で参加操作が必要な場合は、**まずWebコントローラーから参加操作を行います。**

Webコントローラーで操作できない場合や、Neat端末の状態に問題がある場合は、**Neat Pulseから端末を遠隔操作**します。

[Neat Pulseの補助操作を確認する](../neat-pulse/){ .md-button }

---

## 3　左右の画面を確認する

受信校の2画面に、授業で使用する映像が正しく表示されていることを確認します。

ビューはあらかじめ授業用のデフォルト設定にしているため、通常は毎回変更する必要はありません。

必要な場合のみ、Webコントローラーから表示切替やピン留めなどを行います。

---

## 4　授業開始前の最終確認

授業を始める前に、次の点を確認します。

- 受信校がZoomミーティングに入室している
- 配信教員の映像が意図した画面に表示されている
- 画面共有を使用する場合、共有資料が正しく表示されている
- 受信校のセルフビューが表示されていない

問題がなければ、授業を開始します。
