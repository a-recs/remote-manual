# 5　授業中の基本操作

授業中によく使う基本操作をまとめます。

!!! tip "書き込む前に"
    授業中の説明や板書は、基本的に **板書レイヤー** に書き込みます。

## よく使う操作

| 操作 | こんなときに使う |
|---|---|
| **ペン** | 教材へ手書きで書き込む |
| **消しゴム** | ペンで書いた線を消す |
| **選択** | 図形・画像・文字を移動・削除する |
| **元に戻す** | 直前の操作を取り消す |
| **ページ操作** | 使用するページへ移動する |
| **拡大・縮小** | 数式や図などを大きく表示する |
| **モニタ** | 生徒の書き込みや学習状況を確認する |

---

## 5-1　ペンで書く

**ペン**を選択し、教材上に書き込みます。

色や太さは、必要に応じて変更します。

!!! tip "授業中の書き込み"
    生徒のノートにも残したい説明や板書は、**板書レイヤー**に書き込みます。

---

## 5-2　手書きした線を消す

ペンで書いた線を消す場合は、**消しゴム**を使用します。

!!! tip "消したいものによって操作が違う"
    **ペンで書いた線 → 消しゴム**  
    **図形・画像・文字 → 選択して削除**

---

## 5-3　図形・画像・文字を選択する

図形、画像、文字などを動かしたり削除したりする場合は、**選択**を使用します。

1. **選択**を選びます。
2. 操作したいものを選択します。
3. 必要に応じて移動・削除します。

---

## 5-4　元に戻す

書き込みや操作を間違えた場合は、**元に戻す**を使用します。

直前の操作であれば、消しゴム等で修正するより簡単に元の状態へ戻せます。

---

## 5-5　ページを移動する

ページ一覧から、授業で使用するページへ移動します。

必要に応じてページの追加・削除もできます。

!!! warning "ページを削除するとき"
    使用しているページを誤って削除しないよう、ページ番号や内容を確認してから操作します。

---

## 5-6　拡大・縮小する

数式、グラフ、図、細かな文章などを説明するときは、必要に応じて画面を拡大・縮小します。

説明が終わったら、全体が見える大きさに戻して授業を続けます。

---

## 5-7　生徒の状況を確認する（モニタリング）

右側の **［モニタ］** を選択すると、モニタリング画面が開き、生徒ごとの書き込みや学習状況を一覧で確認できます。

主に次のような確認に使用します。

- 生徒の書き込み状況
- 課題への取り組み状況
- 特定の生徒の学習内容

!!! tip "遠隔授業で活用する"
    生徒の手元を直接確認しにくい場合でも、モニタリングを使うことで、**どこまで取り組んでいるか、書き込みが進んでいるか**を確認できます。
