# Zoom

遠隔授業で使用するZoomについて、**授業を開始するために必要な最低限の操作**だけをまとめます。

本マニュアルでは、次の3つを確認します。

1. **ミーティングを作成する**
2. **受信校のビューを設定する**
3. **授業開始前に確認する**

---

## 1　ミーティングを作成する

授業で使用するZoomミーティングを作成します。

### ホストに設定するアドレス

!!! note "後日追記"
    ホストに設定するアドレスは、後日このページに追記します。

### 受信校が入室していない場合

受信校は、原則として各校でミーティングに入室します。

必要な場合は、**Neat Pulseから受信校のNeat端末を遠隔操作して、ミーティングに参加させます。**

[Neat Pulseの遠隔操作を確認する](../neat-pulse/){ .md-button }

---

## 2　受信校のビューを設定する

受信校では、2画面に表示する内容を授業に合わせて設定します。

基本は、次のいずれかです。

- **スピーカービュー ＋ スピーカービュー**
- **スピーカービュー ＋ 共有資料**

受信校のセルフビューは、あらかじめ非表示にする設定で運用します。

---

## 3　授業開始前に確認する

授業を始める前に、**左右それぞれの画面に意図した映像が表示されていること**を確認します。
