# 2　マイボックスとクラスボックス

MetaMoJi ClassRoomでは、遠隔授業の準備と実施で主に **「マイボックス」** と **「クラスボックス」** を使用します。

!!! tip "まずはこの違いだけ覚える"
    **マイボックス＝教材を準備する場所**  
    **クラスボックス＝生徒と授業で使う場所**

---

## 2-1　マイボックスとクラスボックスの違い

|  | マイボックス | クラスボックス |
|---|---|---|
| 主な用途 | 教材を準備・管理する | 授業で教材を使用する |
| 主な利用者 | 教員本人 | そのクラスの教員・生徒 |
| 遠隔授業での使い方 | PDF教材を読み込み、授業の準備をする | 配布された授業ノートを開いて使用する |
| 学校を切り替えたとき | 共通して使用する | 選択した学校に応じて変わる |

**基本の流れ**  
マイボックスで教材を準備 → 授業ノートとして配布 → クラスボックスで授業

---

## 2-2　マイボックス

マイボックスは、**教員個人の教材を準備・管理する場所**です。

複数の学校を担当している場合でも、マイボックスは共通して利用します。

### フォルダを使って教材を整理する

教材が増えてくると目的の教材を探しにくくなるため、必要に応じてフォルダを作成して整理します。

フォルダ構成に決まりはありません。**担当する学校数、教科の特性、教材の使い方に応じて、授業前に教材を探しやすい方法**で整理します。

#### 学校ごとに整理する例

```text
マイボックス
├─ A高校
├─ B高校
└─ 共通教材
```

複数校で異なる教材を使用する場合などに向いています。

#### 単元ごとに整理する例

```text
マイボックス
├─ 01_力学
├─ 02_熱
├─ 03_波動
└─ 04_電磁気
```

同じ教材を複数校で利用する場合などに向いています。

#### 授業回ごとに整理する例

```text
マイボックス
├─ 01_第1回
├─ 02_第2回
├─ 03_第3回
└─ 04_第4回
```

授業の順番に沿って教材を管理したい場合に向いています。

!!! tip "整理のポイント"
    細かく分けすぎるより、**授業直前に目的の教材をすぐ開けること**を優先します。

> **画像掲載予定**  
> ① マイボックス全体  
> ② フォルダを作成する場所  
> ③ フォルダ整理後の例

---

## 2-3　クラスボックス

クラスボックスは、**クラスごとに授業ノートを使用する場所**です。

教員が授業ノートを配布すると、指定したクラスのクラスボックスに表示されます。生徒は、自分が所属するクラスのクラスボックスから授業ノートを開きます。

!!! warning "クラスボックスを開く前に"
    複数校を担当している場合は、**現在選択している学校が正しいことを確認してから**クラスボックスを開きます。

> **画像掲載予定**  
> ① クラスボックス一覧  
> ② 授業ノートが表示されている状態

### クラスボックスを整理する

授業ノートが増えてきた場合は、必要に応じてフォルダを作成します。

#### 学期ごとに整理する例

```text
クラスボックス
├─ 01_1学期
├─ 02_2学期
└─ 03_3学期
```

#### 単元ごとに整理する例

```text
クラスボックス
├─ 01_力学
├─ 02_熱
├─ 03_波動
└─ 04_電磁気
```

クラスボックスは生徒も利用するため、**教員だけでなく、生徒が授業ノートを見つけやすい構成**を意識します。

---

## 2-4　迷ったときの考え方

教材を作成・読み込み・整理するときは **マイボックス**、生徒に配布して授業で使用するときは **クラスボックス** と考えます。

!!! example "例：PDF教材を使って授業をする場合"
    1. PDF教材を準備する
    2. マイボックスに読み込む
    3. 授業ノートとしてクラスへ配布する
    4. クラスボックスに表示された授業ノートを開く
    5. 授業を実施する

次は、実際に **PDF教材をMetaMoJiへ読み込み、授業ノートとして配布する方法**を確認します。
