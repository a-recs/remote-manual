# Zoom

遠隔授業で使用するZoomの操作をまとめています。

!!! tip "基本の運用"
    受信校のZoom操作は、**Zoom RoomsのWebコントローラーを優先して使用します。**

    **Neat Pulseは補助的に使用**し、Webコントローラーで対応できない場合や、Neat端末そのものの状態確認・遠隔操作が必要な場合に使用します。

確認したい内容を選択してください。

## Zoom Rooms WebコントローラーとNeat Pulseの使い分け

| 操作 | 基本的に使用するもの |
|---|---|
| 受信校のZoom参加状況を確認する | **Zoom Rooms Webコントローラー** |
| 受信校をZoomミーティングへ参加させる | **Zoom Rooms Webコントローラー** |
| Zoomの参加者・表示などを操作する | **Zoom Rooms Webコントローラー** |
| Neat端末の状態確認・端末そのものの遠隔操作 | **Neat Pulse** |
| Webコントローラーで対応できないトラブル | **Neat Pulse** |
